IMU parser — extraction & normalization rules

Label detection

Match IMU, IMU performance, Gyroscope, Gyro, Accelerometer, Bias in-run, Random walk, IMU raw data, IMU rate. Use fuzzy matching.

Candidate blocks selection

IMU specs often appear in grouped blocks or tables. When label found, capture the entire nearby block (±3 lines or same bounding box cluster). If separate gyro/accel entries exist split accordingly.

Tokenization & key extraction

Identify tokens for these categories:

Gyro range (e.g., ±500 °/s), gyro bias (2.7 °/hr), gyro noise density (0.15 °/√hr or 0.15 °/√hr), gyro random walk.

Accel range (e.g., ±30 g), accel bias (2.7 μg or 2.7 μg), accel noise density (17 μg/√Hz).

IMU raw data rate (e.g., IMU raw data 200 Hz), IMU update frequency.

Normalize degree symbols and micro (μ) characters; accept ug, u g, μg.

Unit recognition & canonical units

Gyro range: °/s (degrees per second).

Gyro bias: °/hr. If given as deg/hr or °/hr normalize to °/hr.

Gyro noise: °/√hr or °/√hr (keep standard).

Accel: g or μg as appropriate. Normalize accelerometer bias to μg.

IMU sampling rates as Hz.

Parsing rules & normalization

Gyro range: capture signed range ±X °/s. Output gyro_range: ±X °/s.

Gyro bias in-run instability: capture X °/hr → gyro_bias: X °/hr.

Gyro noise density/random walk: capture X °/√hr or X °/√Hz and label accordingly.

Accel: accel_range: ±Y g, accel_bias: Z μg, accel_noise: N μg/√Hz. Convert mg to μg (1 mg = 1000 μg) if needed.

IMU rates: imu_raw_rate: 200 Hz, imu_output_rate: 200 Hz as provided.

Grouping & output format

Single-field canonical string or structured subfields:

Gyro: range ±500 °/s; bias 2.7 °/hr; noise 0.15 °/√hr
Accel: range ±30 g; bias 2.7 μg; noise 17 μg/√Hz
IMU rates: raw 200 Hz; output 200 Hz


If only partial info present include only those tokens and flag missing fields in Notes.

Special-case heuristics

If numeric values ambiguous (e.g., 0.2 without unit), check for neighboring unit tokens or table header units.

If bias in-run provided as 2.7 - 4.4 μg, capture range and present bias: 2.7–4.4 μg.

Confidence scoring

High (≥90): explicit units for all major IMU tokens and located in IMU block.

Medium (70–89): some fields present but partial or units abbreviated (deg/hr vs °/hr).

Low (<70): values found but units missing; multiple candidate numbers in block.

Fallback & logging

If no IMU label found but gyro/accel tokens exist elsewhere, collect them and mark confidence low.

Log raw block, page number, and extraction method to _parser_log for review.

Examples

Input: Gyroscope performance Input range ±500°/s Bias in-run instability 2.7°/hr Random walk 0.15°/√hr → normalized as above (high).

Input: IMU raw data 200 Hz → IMU rates: raw 200 Hz (high).
