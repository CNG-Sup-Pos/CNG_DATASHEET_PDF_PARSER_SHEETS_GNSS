weight_parser — extraction & normalization rules (g / kg)

Label detection

Match aliases: Weight, Mass, Net weight, Gross weight.

Use fuzzy matching; prefer lines in PHYSICAL / PHYSICAL AND ENVIRONMENTAL sections.

Candidate value selection

Look on same line to the right, then next 1–2 lines below, then right-hand column within max_label_distance_px.

Accept tokens with g, kg (case-insensitive). Also accept lb/lbs if present but rare.

Tokenization

Patterns: \d+(\.\d+)?\s*(kg|g|lb|lbs).

Recognize ranges like 0.85–1.0 kg or 850 g.

Unit recognition & canonical unit

Canonical unit: g. Convert kg→g (×1000). If lb present convert to grams (1 lb = 453.592 g) unless config sets preference.

Preserve decimals with one decimal if fractional grams result from conversion.

Parsing & normalization

Single value: convert and output {weight} g (integer if whole grams, else one decimal).

Range: convert both endpoints and output min–max g.

If separate net/gross values present capture both as net: X g; gross: Y g.

Ambiguity resolution

If numeric value lacks unit but context line includes Weight and other specs show similar magnitude (e.g., 850 in device context), assume grams if value > 20 and < 50000; else require manual review.

If multiple numeric tokens found near label, choose one with unit present; else choose nearest numeric.

Confidence scoring

High: explicit unit with conversion.

Medium: unit inferred from context (e.g., value 850 near Weight → assume g).

Low: ambiguous numeric without unit far from label.

Edge cases & heuristics

When weight given as 0.85 kg, convert to 850 g.

When given like Weight 1.1 kg (850 g without mount), capture both and prefer mounted 1.1 kg as primary if label indicates packaging; place note with alternate.

Fallback & logging

If no weight token found near label, scan PHYSICAL section globally for g/kg tokens and pick nearest numeric to Weight header. Log low confidence.

Examples

Weight 497 g → 497 g.

Weight 0.85 kg → 850 g.

Weight: 1.1 kg (box) → 1100 g; Notes: includes packaging.
