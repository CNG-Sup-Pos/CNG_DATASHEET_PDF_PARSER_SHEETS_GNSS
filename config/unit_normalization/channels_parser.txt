channels_parser — extraction & normalization rules (numeric counts of tracking channels)

Label detection

Match aliases: Channels, Hardware channels, Tracking channels, Number of channels, CH, Tracking channels.

Use fuzzy matching and prefer PERFORMANCE or HARDWARE sections.

Candidate value selection

Look same-line right, then next 1–2 lines below, then within right-hand column cluster.

Accept single integers or integer ranges and phrases like 544 hardware channels, 544 channels, up to 544 channels.

Tokenization

Extract integer tokens with optional qualifiers: \b([0-9]{2,5})\b and patterns up to \d+, max \d+, \d+\s*channels.

Normalize thousands separators (, or . depending on locale) by removing them before parsing.

Unit recognition & canonical units

Canonical representation: integer number followed by channels (e.g., 544 channels).

If phrases indicate types (e.g., hardware channels, tracking channels) capture type in parentheses: 544 channels (hardware).

Parsing & normalization logic

If range given (200–544) use max form: choose the upper endpoint as primary and capture range in Notes. Output 544 channels and Notes: range 200–544.

For up to or max phrases, treat same as upper bound.

If multiple different channel counts appear (e.g., tracking 544, correlators 2048), prefer tracking channels as canonical; log others in Notes.

Ambiguity resolution

If multiple integers nearby, prefer the one directly adjacent to label or with explicit channels token.

If no explicit channels token but single integer in same performance block, use heuristics: if value is in plausible channel ranges (≥16 and ≤20000) accept; else mark low confidence.

Confidence scoring

High: explicit channels token, integer parsed, adjacency good.

Medium: explicit max/up to or type qualifies but ambiguity exists.

Low: inferred integer without channels token.

Fallback & logging

If none found near label, scan the entire PERFORMANCE/HARDWARE block for integers with channels or hardware context.

Log filename, page, extracted integer(s), chosen value, method, confidence.

Examples

544 Hardware channels for simultaneous tracking → 544 channels (high).

Up to 544 channels → 544 channels; Notes: 'up to' qualifier.

Tracking 544, Correlators 2048 → 544 channels; Notes: correlators 2048.
