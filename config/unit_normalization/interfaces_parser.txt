interfaces_parser — extraction & normalization rules (normalize RS232, CAN-FD, USB2.0 → consistent schema)


Label detection

Match aliases: Interfaces, Connectivity, I/O, Ports, Connections, Connectors, Communication.

Prefer CONNECTIVITY or INTERFACES sections or spec table rows.

Candidate block selection

Capture the immediate line and the bounded column block containing interface tokens. Often a comma-separated list or multiple lines each listing a port.

Tokenization

Split by , ; / | and line breaks. Trim whitespace and normalize terms.

Map common variations: RS232/RS-232, RS422/RS-422, USB/USB 2.0/USB full speed, Ethernet/LAN/10/100Mbps, CAN/CAN-FD, Wi-Fi/WiFi, Bluetooth/BT.

Canonical mapping

Canonical interface names: Ethernet, USB, RS232, RS422, CAN, CAN-FD, Serial, PPS / 1PPS / xPPS, Event marker, GPIO, I2C, SPI, Cellular (LTE/4G/5G), Wi-Fi, Bluetooth, Souriau, TE AmpSeal, NMEA, GNSS antenna (TNC/SMA/N-type).

For Ethernet capture speed if present: Ethernet (10/100 Mbps).

Parsing & normalization logic

Output comma-separated canonical names with qualifiers: Ethernet (10/100 Mbps), USB (device), RS232 x2, CAN-FD, PPS out, Event marker.

If counts present (e.g., RS232 x2) include them: RS232 (2 ports).

If connector types listed (e.g., Antenna 2 x TNC) include as GNSS antenna connectors: 2×TNC.

Ambiguity resolution

If Serial used without spec, map to RS232 only if context suggests legacy serial; else leave canonical as Serial (unspecified) and flag.

If vendor uses proprietary connector names (Souriau/ODU), include token and map to Connector: Souriau rather than guessing function.

Confidence scoring

High: token matches canonical list and adjacency good.

Medium: token ambiguous (e.g., serial) or missing counts/qualifiers.

Low: inferred from context or scattered mentions without label.

Fallback & logging

If no explicit Interfaces section, scan headers and footers for connectivity tokens (e.g., Ethernet near top/bottom).

Record all discovered tokens in _parser_log and flag ones mapped with low confidence.

Examples

Interfaces: 3×RS232, USB full speed (device), Ethernet 10/100 Mbps, CAN/CAN-FD, PPS out, Event markers → RS232 (3 ports), USB (device), Ethernet (10/100 Mbps), CAN, CAN-FD, PPS out, Event markers (high).

Connectivity: RS232, CAN, TCP/IP → RS232, CAN, Ethernet (TCP/IP) (medium).
