formats_parser — extraction & normalization rules (NMEA, RTCM, RINEX, vendor formats → consistent list)

Label detection

Match aliases: Formats, Output formats, Input formats, Data formats, File formats, Protocol support, Supported formats.

Prefer COMMUNICATION, OUTPUTS, DATA, or SOFTWARE spec blocks and table rows.

Candidate selection

Capture the list block (same bounding box) or the right-side value for the Formats label.

Accept comma/semicolon/line-separated tokens and inline mentions across a block.

Tokenization

Split on , ; / | and newlines. Trim whitespace and trailing punctuation.

Normalize common shorthands and variants (NMEA 0183, NMEA0183, NMEA).

Canonical mapping (target outputs)

Map tokens to canonical set:

GNSS / telemetry: RTCM v2.x, RTCM v3.x (MSM), CMR, CMR+, SPARTN, UBX

Observations / raw: RINEX v2, RINEX v3, SBF, Septentrio SBF

Navigation / sentences: NMEA 0183, NMEA 2000

Config / transport: CSV, JSON, FTP, HTTP, TCP/IP

Proprietary: preserve vendor token (e.g., SBF, Septentrio Binary Format)

If version numbers present (e.g., RTCM v3.2) preserve them.

Parsing & normalization rules

Output as comma-separated canonical tokens, preserving versions: e.g., RTCM v3.x, NTRIP (client), RINEX v3, SBF, NMEA 0183.

Normalize common forms: RTCM 3 → RTCM v3.x; RINEX 3.02 → RINEX v3.

If a token indicates both format and transport (e.g., NTRIP/RTCM), split into NTRIP (caster/client) and RTCM vX.

Ambiguity resolution

If token ambiguous (RTCM without version), record RTCM (unspecified) and mark medium confidence.

If a proprietary acronym unknown, preserve raw token and add Notes: unknown format token with location.

Confidence scoring

High: explicit canonical token present (e.g., RINEX v3.03).

Medium: canonical token present but without version (e.g., RTCM).

Low: inferred from context or split tokens requiring interpretation (e.g., obs → RINEX assumed).

Fallback & logging

If no explicit Formats label, scan OUTPUT / LOGGING / DATA sections for known tokens.

Log raw extracted strings, canonical mapping, page, method, confidence in _parser_log.

Examples

Formats: RTCM v3.x, NTRIP client, RINEX 3, SBF → RTCM v3.x, NTRIP (client), RINEX v3, SBF.

Supports NMEA, CSV, FTP upload → NMEA 0183 (assumed), CSV, FTP. (Note: assume NMEA 0183 unless NMEA 2000 explicitly stated; flag medium confidence.)
